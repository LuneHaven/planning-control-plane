# Rollout Readiness Criteria (demo canonical doc)

> Demo placeholder produced by discussion node P2-A2.

A domain is rollout-ready when:

1. Every gate below has an evidence link (no self-reported status).
2. The sequencing doc names the domain in the current wave.

## Gates

- G1 — canonical docs updated for the domain
- G2 — evidence links verified within the last review cycle
- G3 — no open blocking decision on the domain's planning node
